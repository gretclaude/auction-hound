🐕 Auctionet Favorites Exporter

This tool helps you export your auctionet watchlist to use with Auction Hound.

📋 Method 1: Browser Console (Recommended)

  1. Go to auctionet.com/en/my/watchlist and log in
  2. Click on the "Ended auctions" tab to see your archived favorites
  3. Scroll down to load more items (repeat a few times to load all ~1000)
  4. Open browser console (F12 or Cmd+Option+J on Mac)
  5. Copy and paste this script:
// Extract all favorite items from the page
const items = [];
const itemElements = document.querySelectorAll('a[href*="/en/"]');

itemElements.forEach(elem => {
  const href = elem.getAttribute('href');
  const match = href?.match(/\/en\/(\d+)-(.+)/);

  if (match && match[1]) {
    const itemId = match[1];
    const title = elem.textContent.trim() || match[2];

    // Get image
    const img = elem.querySelector('img') || elem.closest('tr, div')?.querySelector('img');
    const imageUrl = img?.src || img?.getAttribute('data-src') || '';

    items.push({
      itemId,
      title,
      url: `https://auctionet.com${href}`,
      images: imageUrl ? [imageUrl] : [],
      exportedAt: new Date().toISOString()
    });
  }
});

// Remove duplicates
const unique = Array.from(new Map(items.map(item => [item.itemId, item])).values());

// Download as JSON
const dataStr = JSON.stringify(unique, null, 2);
const dataBlob = new Blob([dataStr], { type: 'application/json' });
const url = URL.createObjectURL(dataBlob);
const link = document.createElement('a');
link.href = url;
link.download = 'favorites.json';
link.click();

console.log(`✅ Exported ${unique.length} favorites!`);

This will download a favorites.json file.

Move it to: auction-hound/data/favorites.json

Then:

  1. Go to your watchlist page (logged in)
  2. Load all items by scrolling
  3. Click the bookmarklet
  4. Save the downloaded file to auction-hound/data/favorites.json
⚠️ Important: Make sure to load ALL your favorites by scrolling down on the "Ended auctions" tab before running the export. The script only captures items currently visible on the page.

✅ After Export

Once you have favorites.json in the data folder:

  1. Run npm start to check for similar items
  2. Set up email credentials in .env
  3. Schedule it to run every 3 days
