📥 Export Recent Auctions (Every 3 Days)

⏰ When to use: Run this every 3 days to grab the newest auction IDs.
🎯 Why: Avoids scraping auctionet - you grab IDs manually while browsing!

Instructions:

  1. Go to: auctionet.com/en/search?sort=newest
  2. Scroll down 2-3 times (loads ~100-150 items)
  3. Open browser console (F12 or Cmd+Option+J)
  4. Paste this code:
// Extract item IDs from current page const ids = []; document.querySelectorAll('a[href*="/en/"]').forEach(elem => { const href = elem.getAttribute('href'); const match = href?.match(/\/en\/(\d+)-/); if (match && match[1]) ids.push(match[1]); }); // Remove duplicates const unique = [...new Set(ids)]; // Download as JSON const data = { exportedAt: new Date().toISOString(), itemIds: unique }; const blob = new Blob([JSON.stringify(data, null, 2)], { type: 'application/json' }); const url = URL.createObjectURL(blob); const a = document.createElement('a'); a.href = url; a.download = 'recent-auctions.json'; a.click(); console.log(`✅ Exported ${unique.length} recent item IDs!`);

5. Save as auction-hound/data/recent-auctions.json

💡 Result: Script only fetches details for these ~100 items
🚀 Speed: Much faster, very light on their servers
😊 Nice: No bot protection issues!
